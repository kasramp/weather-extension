# Publish checklist

1. Merge the pull request to master and wait for the release workflow to finish.
2. Download the `chrome`, `firefox` and `source` zips from the new [GitHub release](https://github.com/kasramp/weather-extension/releases).
3. Chrome Web Store: follow [chrome-web-store.md](chrome-web-store.md) and upload the `chrome` zip.
4. Firefox AMO: follow [firefox-amo.md](firefox-amo.md) and upload the `firefox` zip and the `source` zip.
5. Update the store links in the README once the listings are live.

To be completed at first submission.
